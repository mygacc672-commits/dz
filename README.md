# Termux Hacking Tool Repository 🛠️

A lightweight, modular ethical hacking toolkit optimized for Termux on Android.

## Features
- **Network Scanner**: Ping sweep and port scanning.
- **Recon Module**: Subdomain enumeration and WHOIS lookup.
- **Wi-Fi Monitor**: Basic packet capture interface.
- **Auto Setup**: One-click dependency installation.

## Installation
```bash
git clone https://github.com/yourusername/termux-hack-tools.git
cd termux-hack-tools
chmod +x setup.sh
./setup.sh
